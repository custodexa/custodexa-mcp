# Changelog

All notable changes to `custodexa-mcp` are documented in this file.

## 1.0.0 — first standalone release (2026-09-23)

- Install with `go install github.com/custodexa/custodexa-mcp@latest`, or download a prebuilt archive from the GitHub Release and verify it against `checksums.txt`.
- `initialize` reports the relay's own version in `serverInfo.version`, such as `1.0.0`.
